赛题二：6比特APN S盒低延时实现 — 分析与试错记录

1. 赛题概况

  • 目标: 实现 Browning/Dillon 2010年提出的6比特APN置换（S0），优化硬件延时
  • 评价指标: D_theory（理论延时）和 D_sta（物理综合延时）
  • 约束:
    • 所有输入必须经过 BUF(33.557ps) 或 INV(22.048ps)
    • 只能使用NanGate 45nm库中的标准单元
    • 提交 theory_apn.json（理论验证）和 SB.vhd + 子模块（STA验证）

3. 不同实现策略的理论延时估计

3.1 策略对比表

策略 门级结构 估计 D_theory 优点 缺点
ANF + XOR树 INV→NAND→XOR树 349-432 ps 结构简单、项数少 XOR2=73.019ps太慢
NAND树 (SOP) INV→NAND→NAND级联 186-214 ps 使用快速NAND门 项数多、需要多级
MUX分解 Shannon分解+MUX级联 257-274 ps 可递归简化 MUX2=75.175ps较慢
GF(64)立方 x³ on GF(64)+仿射 未验证 利用代数结构 S0不是简单的x³

3.2 各策略详细分析

ANF + XOR树： - 路径：INV(22.048) + NAND(27.886-44.487) + ceil(log2(n)) × XOR2(73.019) - 对于18项的y0：22.048 + 34.767 + 5×73.019 = 421.9 ps - ANF项数（11-23）比SOP项数（13-17）少，但XOR2太慢

NAND树 (SOP)： - 路径：INV(22.048) + NAND3(34.767) + NAND4(44.487) + NAND4(44.487)（4层） - 估计：22.048 + 34.767 + 44.487 + 44.487 = 145.8 ps（最优4层） - y2需要17项，是最复杂的 → 需要4层NAND → 约186 ps

MUX分解： - 路径：INV(22.048) + max(子树延时) + MUX2(75.175) - 递归3-4层 → 267-274 ps

4. 与SPEEDY S盒的对比

SPEEDY S盒使用标准NAND树结构： - 结构：BUF(33.557) → NAND3(34.767) → NAND4(44.487) - D_theory = 112.811 ps - 使用3输出NAND_TREE_1x2_3x3（1个NAND2+3个NAND3 → NAND4） - 使用3输出NAND_TREE_4x3（4个NAND3 → NAND4）

S0比SPEEDY更复杂：SPEEDY各输出只需4个乘积项（2层NAND即可），S0各输出需要13-17个乘积项（需要3-4层NAND）。

5. GF(64)代数分解探索

5.1 尝试的分解

  1. x → x³ on GF(64)：不是置换（gcd(3,63)=3，3-to-1映射）
  2. x → x + x³ on GF(64)：对多个不可约多项式测试，与S0不直接匹配
  3. Dillon构造：F(x) = x + Tr(x³ + x⁵) 或类似形式，需要具体验证
  4. 仿射等价搜索：2^36种可能的线性变换，无法穷举

5.2 已知参考文献

  • Decomposition of Dillon’s APN permutation with efficient hardware implementation
  • On the Classification of Dillon’s APN Hexanomials
  • Cryptanalysis of a Theorem: Decomposing the Only Known Solution to the Big APN Problem

7. 最优延时路径分析

以INV(22.048)作为输入缓冲（不用BUF，节省11.5ps）：

层数 结构 总延时 表达能力
2层 INV→NAND2→NAND2 77.8 ps 2个2文字乘积项的OR
2层 INV→NAND3→NAND4 101.3 ps 4个3文字乘积项的OR
3层 INV→NAND2→NAND2→NAND2 105.7 ps 级联NAND，受限于扇入
3层 INV→NAND2→NAND4→NAND2 116.9 ps 2组OR后再OR
3层 INV→NAND3→NAND4→INV→NAND2 151.4 ps 8个乘积项的OR（两组4项）
4层 INV→NAND3→NAND4→INV→NAND4 167.8 ps 16个乘积项的OR（四组4项）

关键约束：S0每个输出需要13-17个SOP项 → 至少需要4层NAND逻辑 → D_theory ≥ 167 ps。

8. CHES 2026论文方法在S0上的应用前景

Jia等人的方法核心是： 1. 取反模式(NPS)：用NAND门（带反相输入）高效表示多个ANF单项式 2. 可吸收合并：低深度项并入高深度项的XOR树中，不增加关键路径 3. 项迁移：在不同深度层级间重分配项以实现平衡

对S0的潜在改进： - 如果能将SOP项数从13-17减少到8个左右 → 可以用3层NAND结构 → D_theory降到151 ps - 更激进：减少到4个 → 2层NAND → D_theory降到101 ps（但可能性很低）

9. 实现中的问题和教训

9.1 SOP最小化的问题

  • 贪心集合覆盖找到了13-17项，但可能不是最优的
  • 精确最小化算法（分支定界）在实现时因除零错误崩溃
  • 需要更好的逻辑最小化方法（可能用Espresso启发式算法）

9.2 NAND树架构问题

  • NAND1不存在：单文字项需要特殊处理（INV或BUF）
  • 多级NAND树（>4项）的输出组合逻辑有误：
    • NAND(NAND(NOT(P1),NOT(P2)), NAND(NOT(P3),NOT(P4))) = NOT(G1 AND G2)，不等于G1 OR G2
    • 正确做法：NAND(INV(G1), INV(G2)) = G1 OR G2
  • 需要额外的INV层级来正确实现多组OR

9.3 搜索空间

  • 对6比特函数穷举搜索门级实现：Level-1有约1600个候选门，Level-2组合爆炸
  • 完全穷举不可行，需要启发式方法

10. 下一步计划

  1. 修正NAND树实现：正确实现多级NAND结构，获得工作基线
  2. 尝试代数分解：研究Dillon APN的已知分解（GF(2³)子域、butterfly结构）
  3. SAT辅助优化：参考CHES 2026论文，对6比特S盒使用SAT求解器寻找最优NPS表示
  4. 共享子表达式：5个共享项不够，需要更主动地寻找公共子表达式
  5. 生成VHDL结构实现：将优化后的门级网表转化为VHD结构化代码（SB.vhd + 子模块）
