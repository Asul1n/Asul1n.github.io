Lambda 匿名函数

发表于2026-04-29|更新于2026-10-02|Distributed System
|浏览量:

1. 什么是 Lambda？

Lambda 表达式是 C++11 引入的匿名函数对象，允许在代码中就地定义函数，无需先声明后定义。适用于：STL 算法谓词、回调、局部辅助逻辑等只需用一次的短函数。

2. 语法结构

一个完整的 Lambda 由五个部分组成：

部分 语法 是否可省略 说明
捕获列表 [ ] 不可省略 决定能访问哪些外部变量
参数列表 ( ) 可省略（无参时） 和普通函数的参数一样
mutable mutable 可省略 允许修改按值捕获的副本
返回类型 -> type 可省略 编译器通常能自动推导
函数体 { } 不可省略 具体逻辑

最简形式：[]{} — 合法的不捕获、无参、空函数体 Lambda。

3. 捕获列表 [] — 完整参考

捕获列表决定了 Lambda 内部能访问哪些外部变量，以什么方式访问。

原则：能用具体捕获就别用 [=] [&] — 明确意图，避免意外捕获。

4. 参数列表 () vs 普通函数

  • 无参时括号可省略：[]{ return 42; } 等价于 [](){ return 42; }
  • C++14 起参数可用 auto（泛型 Lambda，见第 7 节）
  • const 形参写法 [](const int& x) 和普通函数一致

9. 常见陷阱

悬垂引用（最危险）

规则：按引用捕获的变量生命周期必须长于 Lambda 本身。返回 Lambda 或把 Lambda 传给异步回调时，按值捕获或 shared_ptr。

捕获 this 后对象被析构
